# Context — VTEX vocabulary

Starter glossary for terms used across skills in this repo. Draft, expand as needed — this is
not an exhaustive VTEX glossary, only the terms that come up when writing or reading these
skills.

- **SE** — Solution Engineer / Solution Engineering, the VTEX team this repo belongs to.
- **Rocketlane** — project/task management tool used to track SE work (e.g. the "SE Co-pilot —
  90 Day Plan" project).
- **Atlas** — VTEX's internal knowledge base agent (MCP `atlas-agent`), used for semantic search
  over VTEX docs and client architecture documents.
- **FastStore** — VTEX's server-rendered storefront framework (v3/v4).
- **RFP** — Request for Proposal; also the name of the team's `vtex-rfp` skill for responding to
  them.
- **OMS** — Order Management System.
- **PIM** — Product Information Management.
- **MCP** — Model Context Protocol, used to connect agents to tools like VTEX Developer, VTEX
  Account, Rocketlane, and others referenced by skills in this repo.

## Contributing to this file

If a skill in this repo uses a VTEX-specific term that isn't listed here, add it via the same PR
that adds or updates the skill.
